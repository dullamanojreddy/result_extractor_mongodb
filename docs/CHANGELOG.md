# Changelog

## [1.0.0] - 2026-07-27

### Added
- Complete VCE Result Analyzer desktop application framework.
- Express backend + SQLite database engine (`vce_results.db`).
- Class Result range scraping and offline database caching system.
- Subject-Wise Result search with instant database lookup and auto-scrape pipeline.
- Excel (.xlsx) and CSV (.csv) exports adhering to strict 4-column requirements.
- Full documentation suite (`docs/` folder with 14 specification files).
- Interactive in-app documentation browser.
- Database Statistics dashboard with SGPA/CGPA distribution, top performers, and mock data generator.
- Resume & checkpoint manager for interrupted batch jobs.
